# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

Junteng Liu is a first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology. Research focuses on natural language processing and machine learning.

## Pages

- **About** (`/`): academic background, research experience, publications, skills and contact information.
- **Publications** (`/publications/`): the full publication list.

## Site configuration

- Site title, author details and contact links: [`_config.yml`](_config.yml)
- Navigation: [`_data/navigation.yml`](_data/navigation.yml)
- About page content: [`_pages/about.md`](_pages/about.md)
- Publications: [`_publications/`](_publications)
